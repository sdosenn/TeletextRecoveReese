# Repository instructions

Do not add to, edit, or otherwise modify any README file unless the user explicitly requests a README change. Implementing a feature, fixing a bug, or changing behavior does not authorize updating the README.

Do not add yourself or any AI assistant as an author or contributor. Commit messages, pull requests and files must not contain `Co-Authored-By` trailers, "Generated with" lines or any other attribution to an AI tool. Use exactly the commit message the user gives.
